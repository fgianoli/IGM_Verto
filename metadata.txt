about=Plugin for QGIS 3 and 4 that converts coordinates using the IGM "Verto online" REST API (official Italian national grids), more accurate than standard PROJ transformations between Italian datums (Monte Mario/Roma40, ED50, IGM95, ETRS89/RDN2008). Features: reproject vector layers, manual coordinate conversion, batch conversion from CSV, map-click tool and a Processing algorithm. Requires an internet connection. --- Plugin per QGIS 3 e 4 che converte coordinate usando l'API REST "Verto online" dell'IGM (grigliati nazionali ufficiali), piu' precisa delle trasformazioni PROJ standard tra i datum italiani (Monte Mario/Roma40, ED50, IGM95, ETRS89/RDN2008). Funzioni: riproiezione di layer vettoriali, conversione manuale, conversione batch da CSV, strumento di click sulla mappa e algoritmo Processing. Richiede una connessione internet. Servizio IGM: https://igmi.esercito.difesa.it/servizi/verto-online/

changelog=
    1.4.3 - Certificato IGM scaduto: il plugin torna a funzionare senza intervento dell'utente. Se QGIS rifiuta la connessione, la richiesta viene ripetuta accettando solo l'errore "certificato scaduto" e solo per il certificato IGM noto (impronta fissata): catena, nome host e identita' del server restano verificati, ogni altro errore o certificato e' rifiutato. Quando l'IGM rinnova il certificato il ripiego non viene piu' usato. Rimossa l'opzione "Ignora errori del certificato SSL" introdotta nella 1.4.1: non serve piu' e disattivava ogni verifica
    1.4.2 - Revisione generale. Sicurezza: la chiave IGM non e' piu' proposta come valore predefinito nell'algoritmo Processing (restava in chiaro nella cronologia) ed e' salvata cifrata nel gestore di autenticazione di QGIS. Rete: blocchi da 5000 punti con due nuovi tentativi sugli errori di rete, coordinate ripetute inviate una sola volta, un solo tentativo per sessione di leggere l'elenco SRS a server irraggiungibile, cache dell'elenco rinnovata ogni settimana. CSV: virgola decimale accettata, righe saltate contate, pulsante Annulla funzionante, caricamento come punti anche senza intestazione. Altro: nomi di output unici nel batch con sottocartelle, messaggio chiaro se il CRS del progetto non e' gestito (click sulla mappa), controllo stesso datum in Processing, codici legacy nell'elenco di ripiego, compatibilita' enum QGIS 4 nel salvataggio su file
    1.4.1 - Certificato SSL del server IGM scaduto (7 novembre 2026): messaggio d'errore esplicito e nuova opzione in Impostazioni "Ignora errori del certificato SSL (non sicuro)", disattivata di default e con avviso, da usare solo finche' l'IGM non rinnova il certificato
    1.4.0 - Scheda Layer: nuova modalita' "Piu layer del progetto" per riproiettare piu layer vettoriali caricati in una sola operazione (elenco con caselle, seleziona/deseleziona tutti, origine letta dal CRS di ciascun layer, output in memoria o in cartella, layer non convertibili saltati e segnalati)
